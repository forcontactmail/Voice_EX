# Voice_EX

## Голосовая практика

Откройте страницу через локальный веб-сервер, например:

```sh
python3 -m http.server 4173
```

Затем перейдите на `http://localhost:4173`. Если вы не сохраняли свой список, автоматически загрузится пример из `phrases.txt`.

Текстовый файл должен содержать по одной паре на строку: русская фраза, разделитель `|` или Tab, английский перевод. Например:

```text
Доброе утро. | Good morning.
Как вас зовут? | What is your name?
```

Распознавание речи использует Web Speech API браузера и доступно не во всех браузерах; используйте Chrome или Edge и разрешите доступ к микрофону.

Во время практики произнесите перевод по-английски. Чтобы сразу повторить исходную фразу, скажите “Repeat phrase”; после распознавания перевода скажите «Готово» для проверки или «Повтори фразу» для повтора. При ошибке приложение сначала озвучит распознанный ответ, а затем правильный перевод. Английский перевод озвучивается английским голосом.

Свой список можно загрузить из текстового файла, отредактировать в поле и сохранить кнопкой «Сохранить список». Формат: одна пара «русская фраза | английский перевод» на строку; Tab тоже подходит. Сохранённый список автоматически используется при следующем открытии страницы. Выбранные русский и английский голоса также сохраняются в текущем браузере. Доступные голоса зависят от браузера и установленных в системе голосовых пакетов.
