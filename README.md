# Voice_EX

## Голосовая практика

Откройте страницу через локальный веб-сервер, например:

```sh
python3 -m http.server 4173
```

Затем перейдите на `http://localhost:4173`. Если список ещё не сохранён, пример `phrases.txt` загрузится автоматически.

Текстовый файл должен содержать по одной паре на строку: русская фраза, разделитель `|` или Tab, английский перевод. Например:

```text
Доброе утро. | Good morning.
Как вас зовут? | What is your name?
```

Для внешнего URL сервер файла должен разрешать запросы с этого сайта через CORS. Распознавание речи использует Web Speech API браузера и доступно не во всех браузерах; используйте Chrome или Edge и разрешите доступ к микрофону.

Загрузите свой `.txt`-файл через поле выбора файла или вставьте пары в редактор. Нажмите «Сохранить список», чтобы применить фразы и сохранить их в браузере. В настройках «Голоса» можно выбрать русский и английский голоса; выбранные голоса также сохраняются в браузере. Список голосов зависит от браузера и установленных в системе голосовых пакетов.

Во время практики произнесите перевод по-английски. Чтобы сразу повторить исходную фразу, скажите “Repeat phrase”; после распознавания перевода скажите «Готово» для проверки или «Повтори фразу» для повтора. При ошибке приложение сначала озвучит распознанный ответ, а затем правильный перевод.
